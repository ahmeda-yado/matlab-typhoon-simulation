# matlab-typhoon-simulation
台風が反時計回りにしか渦巻かないのをシミュレーションで確かめたい。

台風が反時計回りにしか渦巻かないのは、コリオリの力という、地球の自転によって生まれる見かけ上の力の影響である。matlab上でコリオリの力の公式を実際に扱って、本当に反時計回りになるか確かめる。

![demo](images/taifu_02.gif)

---

## 実行方法
動作はMATLAB2023b及び2025bでしか確認していない。matlabで実行する前に選択したフォルダとサブフォルダをパスに追加する必要がある。matlab上でtaifuフォルダを右クリック→「パスに追加」→「選択したフォルダーとサブフォルダー」をクリックでパスに追加される筈。その後、do_this_firstly.mを実行し、その後にdo_this_secondly.mを実行する。

## 工夫した点
・空気塊の動きを分かりやすくするために、たまに有色の空気塊が混ざるようにした
・台風から離れすぎないランダムな位置に空気塊を発生させるために、台風と同じ地点に空気塊を生成し、その上でそれをランダムな回転軸でpi/20回転させるようにした
・速度など完全に実値通りではないものもあるが、コリオリの力や気圧傾度力など、ある程度実際の動きに沿うように設定した
・地球の海面部分の半径とする球より外側にある点の色を変えることにより、地表と海を塗り分けた
・MATLAB2025bはいきなり重いファイルを開くとMATLABがフリーズすることがあるので、動作の軽いファイルで先にMATLABを動かすようにした
